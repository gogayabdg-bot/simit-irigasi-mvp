# SIMIT MVP — Sistem Informasi Irigasi Terpadu (DSDA Jawa Barat)

Dokumen rancangan: "SIMIT DSDA Jabar v2.0" (24 Okt 2026). MVP setara R0.1–R0.3: master D.I., Blangko 04-O/06-O/08-O/hujan, mesin Faktor-K, jadwal gilir dasar, PWA lapangan offline.

Menjalankan: `python3 -m http.server 3000` di folder `simit-mvp/`, uji `node verify.js`.

Aplikasi web yang dapat diinstall (menambah ke halaman utama) di Android via manifest + service worker-nya (`sw.js`).
